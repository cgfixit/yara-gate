# YARA-X 1.23.0 to 1.24.0 (2026-11-23)

Source: `main` at `bdd0fa4`, branch `claude/deps-yara-x-1-24-0`. Linux x86_64, Python 3.12.
The only dependency change is `uv lock --upgrade-package yara-x`, written with uv 0.13.9
because the local uv 0.11.32 rewrote the lock's `revision` and an unrelated marker;
`pyproject.toml` keeps `yara-x>=1.20`.

1.24.0 was uploaded to PyPI on 2026-11-20, three days before this change and inside this
repository's seven-day Dependabot cooldown; the maintainer chose to bump now. The GitHub
release notes were not reachable from the session (the API returned 403), so the comparison
below is empirical only. Pull request #339 holds a research record that read the upstream
commits.

`MATCH_LIMIT` assumes the engine keeps 1,000,000 matches a string. `DEFAULT_MAX_MATCHES_PER_PATTERN`
is `1_000_000` at both the `v1.23.0` and `v1.24.0` tags (`lib/src/scanner/matches.rs`), and the
comment in `rules.py` now names 1.24.0.

`probe_yara_compat.py`, `probe_rule_coverage.py --verify`, `probe_detection_gaps.py --verify`,
`check_rules_lock.py`, `check_scan_only.py`, `check_intake.py`, `yara-gate selftest`, Ruff,
and `mypy --strict src scripts` pass on 1.24.0.

## Demo recordings

`web-demo/recordings.json` was regenerated. Against the reviewed baseline the diff is
provenance only: 276 `engine_version` values (1.23.0 to 1.24.0), 276 `ruleset_sha256` values
(the digest covers the engine version), and the revision and time of capture. No verdict, rule
id, or view changed.

## Not established

- Vendor packs were not installed or compared across engines; that needs the maintainer's say
  and a disposable rules root. Vendor-rule behavior on 1.24.0 is unknown.
- `uv audit` did not run: `api.osv.dev` was unreachable from the session. This record makes
  no claim about vulnerabilities.
- Timing was not compared against 1.23.0 in this run. Single flood runs in the research record
  read 15 to 25% slower on 1.24.0 with no deadline approached; the worst-case check passes.
- macOS and Windows were not run locally; the hosted jobs on the pull request are the
  evidence for them, including the Windows wheel.
- `docs/rules.md` and `docs/verification/` still name 1.23.0 where a line reports a dated
  measurement; those were not measured again.
