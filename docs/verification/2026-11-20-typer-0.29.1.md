# typer 0.27.3 to 0.29.1 (2026-11-20)

Source: `main` at `eea35f1`. Linux x86_64, Python 3.12, YARA-X 1.23.0. The only change to the
environment is `uv lock --upgrade-package typer==0.29.1`, run with uv 0.13.9 so the lock keeps
its revision; `pyproject.toml` keeps `typer>=0.12`. typer now depends on `pydantic`, which was
already a direct dependency at the same locked version.

0.29.1 was uploaded to PyPI on 2026-11-11, outside the seven-day Dependabot wait. 0.29.2
(2026-11-18) is inside it and was not taken. 0.29.0 is the release that changed behaviour: it
validates parameters through Pydantic and removes `click_type` and some Click attributes of
callback parameters. `src/yara_gate/cli.py` uses none of them.

## What was compared

Both versions ran the same commands with `COLUMNS=100 NO_COLOR=1 TERM=dumb`, a disposable
`HOME`, a disposable `--home`, and the checkout's `rules/`.

`--help` for the root, all 13 commands, `rules`, and its 3 subcommands (17 screens), each exit 0
on both. Two differences:

| Where | 0.27.3 | 0.29.1 |
| --- | --- | --- |
| Every flag without a value (`--help`, `--json`, `--dry-run`, ...) | no type column | `<bool>` |
| `scan` usage line and argument row | `[PATH...]`, `<str>` | `[PATH...]...`, `<list[str]>` |

The second comes from `metavar="PATH..."` in `cli.py`: 0.29 appends its own `...` to a list
argument. `metavar="PATH"` prints `[PATH]...` on 0.29.1 but `[PATH]` on the older releases the
bound still allows, so it is left as it is.

24 invocations, 20 of them a bad argument. The exit code is the same on both versions in every
one: 2 for each rejected argument, 0 for a clean scan, a stdin scan, `--version`, and
`--timeout 1_0`, which both versions read as 10.

| Bad argument | Exit, both | Message on 0.27.3 | Message on 0.29.1 |
| --- | --- | --- | --- |
| `--timeout abc`, `--port abc` | 2 | `'abc' is not a valid int.` | `Input should be a valid integer, unable to parse string as an integer` |
| `replay --timeout 1.5` | 2 | `'1.5' is not a valid int range.` | the same integer message |
| `replay --timeout 0` | 2 | `0 is not in the range 1<=x<=86400.` | `Input should be greater than or equal to 1` |
| `replay --timeout 86401` | 2 | `86401 is not in the range 1<=x<=86400.` | `Input should be less than or equal to 86400` |
| `--policy bogus`, `""`, `Agent-Ingest` | 2 | `'bogus' is not one of ...` | `Value error, 'bogus' is not one of ...` |

Unchanged in text and exit: an unknown command, no command, an unknown option, an option
missing its value, a missing required argument or option, an extra positional, a flag given a
value, a negative `--timeout`, and a path that does not exist.

No file under `src/`, `tests/`, `docs/`, or `scripts/` quotes one of the changed messages.
