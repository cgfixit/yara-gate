## What this does not establish

- These are curated synthetic pairs written beside the rules. 0 findings on 34 twins is
  evidence for these examples, not a false-positive rate for other content; the separate
  corpus and sweeps are in [measured precision](../rules.md#measured-precision).
- One browser, headless. No screen reader was run; the new cards are buttons with text
  content, and the marks are hidden from assistive technology because the counts beside
  them say the same.
- The technique label is derived from finding fields. It says which view or check produced
  the finding, not what an attacker intended.
- The hosted page changes only when this merges and `main`'s checks are green; the deploy
  then re-records at the merged commit and stops if an outcome differs from the baseline.
- Hosted CI had not run on these commits when this was written.
