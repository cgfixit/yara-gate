- A finding inside a mail part read *inside archive member 1, the member's own bytes*. The
  recording's member path names its container (`zip:1`, `mime:0`), so both pages now say
  *message part* and *the part as a mail reader decodes it* for a MIME part. The card is
  now *Inside an archive or message*. The workbench had said *the original bytes* for any
  member's raw view; it now says *the member's own bytes*, as the public page does.

  unfolded view had already matched the same rule. The workbook's heading `Q3 vendor
  totals` folds to letters, so the folded copy of the view differs, and the plain sentence
  matched in both. A folded finding now counts only when the unfolded view did not match
  that rule. Computed over the recording before and after: only the new workbook pair moves
  (off *Disguised spelling*); no earlier pair changes card.
- `pdf-text` was named *read through its font maps*. The new PDF is read through its
  font's own encoding, with no map; the name is now *read through the encoding or map of its
