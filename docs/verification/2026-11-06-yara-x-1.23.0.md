# YARA-X 1.22.1 to 1.23.0 (2026-11-06)

Source: `main` at `7f9934c`, branch `deps/yara-x-1.23.0`. Linux x86_64, Python 3.12. The
only change is `uv lock --upgrade-package yara-x`; `pyproject.toml` keeps `yara-x>=1.20`.

1.23.0 was uploaded to PyPI on 2026-11-05, inside this repository's seven-day Dependabot
cooldown; the bump was requested directly. Its sdist has no changelog and the GitHub release
notes were not reachable from the session, so the comparison below is empirical only.

`check_rules_lock.py`, `check_scan_only.py`, `check_intake.py`, `check_text_controls.py`,
`probe_rule_coverage.py --verify`, `yara-gate selftest`, ruff, `mypy --strict src`, and the full

## Vendor packs

The three locked packs (yara-forge core `20261004`, signature-base `94a1c48`, elastic
`83e2276`) were installed with `rules install --allow-network` into a disposable rules root;
their hashes matched `rules.lock`. The same root was compiled and used for scans under each
engine, each with its own empty cache directory.

| | 1.22.1 | 1.23.0 |
| --- | --- | --- |
| Compiled rules | 13,631 | 13,631 |
| Skipped vendor files | 13 | 13, the same files |
| 867 files: the 320-file precision corpus, 150 host texts, 200 host PDFs, 132 third-party test PDFs (pikepdf, pypdf), 65 joblib test pickles | | identical verdict, incomplete reason, and findings for every file |

The only vendor-rule finding on those benign files under either engine is
`Methodology_Suspicious_Shortcut_Local_URL` on the corpus's local-file `.url`, which
`rules/vendor-overrides.json` already makes advisory.

Scan time for the 867 files: 31.0 s on 1.22.1, 29.9 s on 1.23.0.

## Not updated

The other packages with newer releases (msoffcrypto-tool 6.1.0, platformdirs 4.14.5, pydantic
2.14.3 with pydantic-core 2.50.4, typing-inspection 0.4.5, watchdog 7.1.0, and the dev tools
ruff 0.17.4 and mypy-extensions 1.2.0) were all uploaded 0 to 2 days before this record, inside
the cooldown, and nothing in the open work needs them. watchdog 7 is a major release that the
folder watcher depends on. They are left to Dependabot's weekly run.
