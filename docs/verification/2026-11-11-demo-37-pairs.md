## A reader fix found while building the pair

`_stored_zip` writes the fixtures uncompressed. On such a package the outer file's own
bytes hold the OpenDocument namespace, so `odf_text_views` read the paragraph a second
time from outside the archive and reported it with no member path. A part is now read only
when it opens as XML, after an optional byte order mark and white space. Packages written
by an office suite are deflated and were not affected.
`probe_odf_reader_agreement.py` after the fix: 0 MISS, 3 wide, 29 ok, as before.
