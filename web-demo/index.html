    Run the real scanner on your own machine
    
      
    From a yara-gate checkout with Python 3.12 and uv installed:
    
      
    uv sync --frozen
uv run yara-gate demo --rules rules
    
      
    Dependency installation uses the network. After installation, the loopback app scans locally with bundled rules. It can accept short pastes; this public page cannot. Vendor installation is a separate, explicit step.
    
      
    
        
    Messages & tool results
    Use agent-ingest before a CyClaw query or a Harness tool response reaches the model. Require a complete clean result.
    
        
    Retrieved documents
    Use agent-document for corpus files that may quote attacks. Accept only complete clean or the exact notes-only record.
    
        
    Keep the boundary
    Read the same bytes that were scanned. Keep content fenced as data and preserve the agent's approval controls. Neither demo installs a consumer integration.

    Privacy and limits, plainly
    
      
    The demo has no analytics, cookies, browser storage, or content submission. Its scripts make no API calls and cannot connect to localhost. Only the static page and its assets load; documentation links navigate when you choose them.
    
      
    GitHub hosts this public site and logs visitors' IP addresses for security. This is not an anonymous or offline service. See GitHub Pages data collection.
    
      
    Recorded results cover only these examples and their pinned source revision. A real clean scan is not proof that content is trustworthy. There is no semantic understanding, OCR, or general decryption, and unsupported or unfinished scans must be held.
