## Review findings on pull requests

Resolve a review thread once its finding is fixed and verified, security findings included:
reproduce the finding, push the fix with its check, reply on the thread with what changed, then
resolve it. Ask the maintainer first only when a fix changes behaviour they would need to weigh
(for example, making a scan fail closed where it passed before), or when a finding is not
reproduced and is left unfixed.
