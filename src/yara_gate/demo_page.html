    Put the gate before the context window
    
      
    
        
    1. Stage untrusted content
    CyClaw: scan incoming messages and staged corpus files before queries or reindexing. Harness: scan attachments, fetched pages, and tool results before prompt assembly.
    
        
    2. Require a complete result
    Messages need a complete clean result under agent-ingest. Retrieved documents can also pass the exact notes-only agent-document check. Exit 0 alone is insufficient.
    
        
    3. Read the same bytes
    Use the scanned buffer or verify its SHA-256. Keep content fenced as data. Blocked, incomplete, missing, or malformed results stay out of the agent's context.
    
      
    
      
    Integration entry points & policy reference
        
    Use scan_bytes(body, name="message.txt", policy="agent-ingest") for messages already in memory. For a staged document:
    
        
    yara-gate scan /path/to/staged-document --json --policy agent-document --home /path/to/private-gate
    
        
    The CLI writes reports under its gate home. Keep synced folders separate from the inbox: copy files out before scanning. The web demo does not install a connector or authorize agent actions.
    
        
      
          
    • agent-ingest: holds every advisory and note. Read only complete clean records.
      • 
          
    • agent-document: holds advisories; permits complete clean and exact notes-only records.
      • 
          
    • default: reports notes and advisories with exit 0. Use for manual inspection.
      • 
          
    • Any policy: block exits 1; incomplete exits 2. A missing result is a failed gate.

    Privacy & scanner limits
        
    Scans go only to this loopback server. The app has no analytics, cloud classifier, browser storage, or scan history. Input and results stay in memory; the server does not save pasted content, write scan reports, or log request bodies. The rule compiler may cache compiled rules locally.
    
        
    Clear removes visible input and results; it is not secure memory erasure or clipboard cleanup. An in-flight server scan may still finish. Browser extensions and the host environment are outside this app's controls.
    
        
    The scanner never executes targets or follows their URLs. It checks known patterns and bounded supported views, not intent or every possible encoding. There is no OCR or general decryption. Rules are never downloaded by this page. A clean result permits reading as data, never obeying embedded instructions.
